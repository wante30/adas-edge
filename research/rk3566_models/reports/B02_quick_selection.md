# B-02：ADAS 候选模型 PC 端快速筛选

只复用 B-01R-Lite 的50张 BDD100K validation 图片与预测缓存；底层 score floor 为0.001、max detections为100，IoU匹配阈值0.5，NMS IoU 0.45，输入512×288，batch=1。阈值统计没有重复推理。753个目标标注包含机动车547（含摩托车）、行人76、自行车7、交通灯123；B-01报告此前将547机动车和3辆摩托车重复相加，造成756，本次已更正。

预处理核对为BGR图像黑边letterbox后转RGB、NCHW float32并除以255；BDD图像与512×288输入同为16:9，实际无padding。网格stride为8/16/32，LTRB距离按网格中心解码，框按`(coord - pad) / scale`还原。与[官方Model Zoo预处理及后处理](https://github.com/airockchip/rknn_model_zoo/blob/837db8e992815ff8647eadb709f07067f4bc3a71/examples/yolov6/python/yolov6.py)一致。

## 表2：RTX 4060 本机测速

预热20次、计时100次，循环使用同一批50帧并同步CUDA。Pipeline计入图像预处理、前向、解码/NMS和坐标映射，不计磁盘读取。FPS按对应平均耗时换算。

| 模型 | 实际后端 | 纯推理 ms / FPS | 完整 Pipeline ms / FPS |
| --- | --- | ---: | ---: |
| YOLOv6n 512×288 | ONNX Runtime CPUExecutionProvider | 53.40 / 18.73 | 64.98 / 15.39 |
| YOLOv8n 512×288 | PyTorch CUDA FP32，RTX 4060 Laptop GPU | 8.55 / 116.94 | 13.94 / 71.72 |
| YOLO11n 512×288 | PyTorch CUDA FP32，RTX 4060 Laptop GPU | 12.39 / 80.70 | 12.88 / 77.63 |

本机 Windows ONNX Runtime 仅有 Azure 与 CPU Provider；WSL 可见4060但没有 ONNX Runtime。因此 YOLOv6n没有可用的GPU测速后端，其CPU耗时不能与两条CUDA结果作速度排名。

## 表3：模型选择结论

| 评估问题 | 结论 | 证据与边界 |
| --- | --- | --- |
| 331个FP是否主要由错误实现造成 | 未发现系统性实现错误，不认为这是主要原因 | 对照 [Rockchip Model Zoo YOLOv6后处理](https://github.com/airockchip/rknn_model_zoo/blob/837db8e992815ff8647eadb709f07067f4bc3a71/examples/yolov6/python/yolov6.py)：官方同样忽略`score_sum`，使用类别最大分数、中心网格加减LTRB距离和逐类NMS。RGB、黑边letterbox、/255、stride网格、0.45 NMS及坐标逆映射一致。目视看到大框落在路面/车头区域，属于模型误检；另有骑手被预测为person但BDD标为rider并按既有评测口径排除。无法将331个FP全部归为模型本身或精确拆分各原因。 |
| 阈值调整后是否仍多于YOLO11n有效检出 | 是，四个阈值下总TP都更多 | @0.45：YOLOv6n 203 TP / 41 FP、Recall 0.270；YOLO11n 180 TP / 22 FP、Recall 0.239。@0.55：176 / 16 对比149 / 14，但YOLOv6n总Recall已降到0.234。 |
| RTX 4060哪款最快 | 纯推理YOLOv8n最快；完整Pipeline本次YOLO11n略快 | 纯推理8.55ms对12.39ms；Pipeline 12.88ms对13.94ms。仅单轮100次测量，Pipeline差值较小；YOLOv6n未在GPU上测，不能作三模型公平排名。 |
| 是否优先开展YOLOv6n ADAS专用训练 | 推荐作为下一阶段优先候选之一 | 中高阈值下仍比YOLO11n多检出目标，说明其召回潜力值得用专用数据训练验证；但精度仍较低，@0.45交通灯为0 TP。结论只适用于这50张快速筛选样本，不代表最终精度排名，也不建议据此替换当前模型。 |
| RK3566验证状态 | 尚未进行 | 未连接或占用RK3566；没有板端速度、内存、温度或NPU精度数据。 |
