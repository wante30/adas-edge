# ADAS Edge 比赛素材库

推荐双击 `open_gallery.cmd` 打开素材页。启动器会在本机启动图片服务并打开浏览器；重复打开会复用已有服务。需要安装 Python 3，图片不会上传到网络。

本机服务运行时可访问：http://127.0.0.1:8766/ （端口占用时自动选择后续端口）。

入口：[素材总览](OVERVIEW.md)；来源与限制见 [质量与来源](QUALITY_AND_PROVENANCE.md)。

素材页提供 21 张核心推荐、54 张精品、361 张原始候选。点击缩略图查看原图和裁剪版本。

如果直接打开 index.html 后浏览器未显示图片，请使用上述启动器。分发素材库时请保留整个目录，单独复制 HTML 不包含图片。
