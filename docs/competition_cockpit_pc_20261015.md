# 比赛车机：本机验收与启动

开始日期2026-10-15，完成验证2026-10-16。原生OpenCV/Pillow窗口，1600×900画布；不使用旧网页，不改冻结模型。此版把真实前视、比赛决策、模拟输入和诊断分开显示。

## 启动

双击工程根目录 `run_competition_console.cmd`。打开官方前视视频12秒位置并暂停，主模型、灯专项和实验危险模块启用；默认路口场景。HUD软件寄存器接收器已启用，界面注明仿真，未写实际硬件。

顶部四个入口对应路口、道路、导航和危险；底部提供当前场景的模拟输入及自动/停止/强制行驶。真实视频运动不会被这些模拟按键改变。车身图来自已保留MIT许可的Carviz模型，只表达模拟状态，不是测得的自车姿态。Tesla-BevCam原版渲染保留在“空间示意”里，距离未标定。

| 操作 | 功能 |
|---|---|
| I / D / N / H | 切换四种比赛场景，保留当前是否受信号控制 |
| 1 / 2 / 3 | 模拟左转、直行、右转车道 |
| 0 / S / G | 自动模拟、停止、强制行驶 |
| Q / E / A | 道路场景请求左变道、右变道、保持直行 |
| J / L | 导航场景请求左右转弯；没有有效导航时仍等待 |
| T | 非路口场景显式设置有/无信号灯，不从切页面暗中推断 |
| B | 选择当前车道的横向R/Y/G灯组；再次B取消；自动回前视画面 |
| V / F / C | 检测标记、诊断、原版空间示意 |
| 空格 / . / R / O | 暂停继续、逐帧、重播、打开视频 |
| Esc | 依次退出选灯、诊断、空间示意；均关闭后退出程序 |

大部分操作都有鼠标按钮。选灯时显示拖框；图像保持源宽高比，黑边和播放栏不能作为灯组坐标。录制时禁止混入另一帧率的视频；异常视频会给出提示。

## 比赛功能的真实状态

路口已用官方视频真实像素验证红停绿行、模拟方向和强制红行报警，灯组位置/车道归属仍来自显式场景配置。主模型和专项模型候选与绑定像素判色的来源分别记录。

道路规则支持实线拒绝、虚线许可、未知拒绝，但视频链路尚未填入左右边界；因此正常道路页显示“车道视觉未接入”。导航没有连接图像/音频解析，无有效指令时等待。危险模式已有图像事件原型，不能把制动灯变亮称为确认急刹，也不能从车辆灯色认定行人闯灯。
