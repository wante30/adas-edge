# Competition performance report

Measured values only: RK3566 NPU-only 320 mean 22.849 ms (43.717 FPS), 416 mean 34.696 ms (28.800 FPS), 640 mean 78.998 ms (12.654 FPS). Historical full pipeline 320 throughput 27.715 FPS and 416 throughput 21.731 FPS. These exclude FPGA PCIe and HDMI output because that hardware path is not available in this checkout.
