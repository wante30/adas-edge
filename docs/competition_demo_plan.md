# Competition demo plan

1. Boot FPGA bitstream and show four input sources/mosaic.
2. Start RK3566 host with fixed model/config and log directory.
3. Play official U-disk intersection clip; show traffic-light state, arrow and stop/alarm overlay.
4. Play lane-change clip; use keys to select left/right and demonstrate dashed/solid behavior.
5. Play pedestrian/obstacle clip; show danger stop.
6. Disconnect/reconnect one source and demonstrate timeout/fail-safe status.

The exact sequence and screenshots must be rehearsed only after FPGA endpoint and clips are available.
