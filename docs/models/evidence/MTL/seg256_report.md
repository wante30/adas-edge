# B-2a MTL RK3566 两项优化实验（A/B）

日期：2026-10-31
输入：`/home/cat/b05g_113421_3s.rgb` 前 60 帧（RGB565 1280×720）
平台：LubanCat RK3566 / RKNN Lite2 2.3.2
对照：B-2a MTL INT8 原版（15 输出，512×288 分割）

## 实验 A：跳过分割后处理

RKNN 仍返回全部 15 个输出，只跳过三个分割头的 Python argmax；检测、NMS、预处理不变。

| 指标 | B-2a 原版 | 跳过分割后处理 |
|---|---|---|
| RKNN 调用 p50 / p95 | 158.8 / 411.9 ms | 133.9 / 480.8 ms |
| 检测后处理 p50 | 10.7 ms | 10.9 ms |
| 分割后处理 p50 | 48.8 ms | 0 |
| 完整单帧 p50 / p95 | 244.6 / 512.2 ms | 156.4 / 509.1 ms |
| 连续 FPS | 3.55 | **4.55** |

提升：FPS +28.2%，单帧 p50 −36.1%。RKNN 调用也降了约 25 ms——RKNN Lite 在未访问分割输出时没有完整取回/反量化那三张大图，所以“跳过 Python 后处理”同时省掉了一部分 runtime 输出开销。

## 实验 B：Seg-256

在 ONNX 图内对三个分割输出各加一个 2×2 AveragePool（stride 2），输出变为 144×256；12 个检测输出不变，权重未重新初始化，仍用同一份 500 张校准。

- ONNX 校验：新分割输出与原 logits 的 2×2 均值池化最大差 **3.8e-6**；12 个检测输出逐元素一致。
- RKNN INT8 文件：`b05n_p2_mtl_b2a_seg256_int8.rknn`，4,933,694 B。
- 分割张量：2,211,840 → 552,960 个值（4× 减少）；float32 8.85 MB → 2.21 MB。

| 指标 | B-2a 原版 | Seg-256 |
|---|---|---|
| RKNN 调用 p50 / p95 | 158.8 / 411.9 ms | **117.8 / 340.2 ms** |
| 分割后处理 p50 / p95 | 48.8 / 63.9 ms | **14.7 / 23.2 ms** |
| 完整单帧 p50 / p95 | 244.6 / 512.2 ms | **161.1 / 436.2 ms** |
| 连续 FPS | 3.55 | **4.79** |

相对原版：FPS +34.9%，单帧 p50 −34.1%，RKNN 调用 −41.0 ms（−25.8%）。

|---|---|

| 车道内线型一致率 | 0.963 |
| 实线一致率 | 0.920 |
| 虚线一致率 | **0.978** |

Seg-256 仍然正常：车道 2.81%、斑马线 1.82%、车道内实线 25.8% / 虚线 74.2%、可行驶 direct 3.19% / alternative 1.37%，无全零或全背景。

## 汇总

| 指标 | B-2a 原版 | 跳过分割后处理 | Seg-256 |
|---|---|---|---|
| RKNN 调用 p50 | 161.2 ms | 133.9 ms | **117.8 ms** |
| 分割后处理 p50 | 49.0 ms | 0 | **14.7 ms** |
| 完整单帧 p50 | 232.3 ms | **156.4 ms** | 161.1 ms |
| 连续处理 FPS | 3.41 | 4.55 | **4.79** |
| 车道预测一致性 | 基准 | 不适用 | 0.794 |
| 虚线预测一致性 | 基准 | 不适用 | 0.978 |

注：表中“B-2a 原版”的 RKNN/分割/单帧/FPS 用上一轮基线 161.2/49.0/232.3/3.41；本次同批复测原版为 158.8/48.8/244.6/3.55。提升比例按同批原版计算。

## 结论

- **没有达到 6 FPS**：最好的是 Seg-256 的 4.79 FPS，跳过分割后处理 4.55 FPS。
- 161 ms 的 RKNN 调用在 Seg-256 下降到约 118 ms（−26%），但仍远高于 B05N 的 46 ms。剩余大头不是分割输出搬运，而是 B-2a 多任务解码器/特征路径本身在 RK3566 上的计算与内存开销。
- 分割后处理从 49 ms 降到 15 ms，是两项里最直接有效的部分；但单帧仍 161 ms，受 RKNN 调用限制。
- Seg-256 的车道/斑马线一致性约 0.77–0.79，边界有可见损失；线型（尤其虚线 0.978）保持较好。若精度优先，不建议直接用 Seg-256 替换原分割输出。
- 按任务要求，A/B 之后停止，不继续尝试其它分辨率或结构。
