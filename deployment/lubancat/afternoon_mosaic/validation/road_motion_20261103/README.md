# Issue #10 道路示意动画

本次仅改变显示层，基于 Issue #10 的车辆防跳版本。车道虚线、未知边界点线和路侧横向网格按照渲染单调时钟向自车滚动，不改变车辆轨迹、危险判定或 FPGA 控制。

当前遥测不提供可靠车速，因此使用固定的每秒 6 个相对场景单位作为动画速度，界面明确标注“道路示意动画 · 非实测车速”。这不是实测车速、视觉里程计或真实道路三维重建。输入时间戳超过 500ms 未更新时暂停；恢复不累计停顿时间，单帧推进最多 120ms。切换模型时不重置道路相位。
